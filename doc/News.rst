Version 0.6.0 (2026)
********************

.. topic:: :gh:`v0.6.0 - 29.10.2026 <edaa-org/pyEDAA.ToolSetup/releases/v0.6.0>`

   .. rubric:: Changes

   * pyTooling 10.1 and pyEDAA.CLITool 0.5 are required; Python 3.11 to 3.15 are supported.
   * The GHDL and NVC setups can be imported again on a fresh installation.
   * The copyright holder is *Electronic Design Automation Abstraction (EDA²)*.

   .. rubric:: Documentation

   * The documentation is built with pyTooling.Sphinx: dependency tables, and report pages per testsuite, source file
     and module.
